# 物尽其用 · Material Matters

《缺氧》（Oxygen Not Included）的材料与工程系统模组。它不增加新材料，也不是单纯改数值，而是让熔点、硬度、电导率、装饰度这些材料属性**真正参与建筑、电网、房间和辐射的运算**，让「用什么材料、建在哪里、怎么布局」成为有取舍的工程决定。

**当前版本 1.0.2** · 需要游戏 build `744825` 或更新 · 本体与 DLC 均可使用 · 无前置 Mod（只用游戏自带的 Harmony）· 界面为简体中文

## 设计思路

- **大多数材料仍然能用。** 不合适的材料通常不被禁止，而是带来效率、维护、能耗或环境上的代价。
- **材料不是升级树。** 钢耐热耐磨却导电差、最易被辐射活化；铜导电最好但耐热一般；铅屏蔽最好却熔点低。没有一种材料在所有场景都最优。
- **复用原版。** 尽量使用原版已有的属性与机制，增加系统之间的联系，不另造一套新玩法。
- **开局不变难。** 前期几乎无感：基础房间保持原版，短线路损耗很小；工程压力在中后期基地扩张时才逐渐出现。

## 四个系统

### 工业：温度与硬度

29 栋工业建筑（金属精炼器、玻璃熔炉、窑炉、各类发电机、净水器、油井等）有了**工作温区**和**硬度要求**。

- **建材决定耐温上限**：最高工作温度 = 主建造材料熔点（K）× 0.75 ×（1 + 材料过热加成），这同时也是建筑的过热温度。低熔点材料造的精炼炉可能够不着高温配方。
- **配方有最佳温区**：区内效率 100%，偏离越远越慢。连续设备和燃料发电机按同一效率同比缩放原料、产物和发电量。
- **内置加热**：高温建筑可用 20–4000 W 滑条预热、补热，加热耗电另计；升温快慢取决于建材热容。
- **运行模式与强制运行**：未接温区输出线时整个工作温区内都能生产，接线后只在最佳温区生产；「强制运行」可越过温区限制。
- **订单排程**：订单按添加顺序轮换执行，温区相近的配方排在一起更省电；建筑信息卡的「订单队列」面板列出全部订单和当前进度。
- **硬度磨损**：每栋建筑按工作强度要求硬度 10、25 或 50（粉碎、压制、钻探类最高，处理液体的最低）；建材硬度不足时照常生产，但会按实际生产时间磨损扣血，硬度差越大磨得越快，需要维修。
- **全局材料调整**：正向过热加成统一为 +60%；深渊晶石可作为矿物原料建材（导热改为 0.1）；接受金属矿石的槽位都可以改用精炼金属。

详见 [建筑系统设计](<docs/Mod玩法设计和修改/2. 建筑系统设计.md>)（含全部建筑参数、配方最佳温区和建材选型参考）。

### 电力：线路损耗

每台用电设备按**从电源到它的最短实际线路**计算输电损耗，线路规划和电线选材从此有了意义。

- 线路越长、负载越高、导线材料电导率越差，损耗越大；大容量导线带小负载也不划算。
- 导线类型决定容量，建造材料决定电导率（铜最好，铁矿、铅等较差），混合线材分段计算。
- 多电源时发电机和变压器输出端先供电，电池只补缺口，同类电源按线路远近取电；变压器两侧、电池充放电分别结算。
- 损耗是真实消耗的电能，在电网信息卡和能源报告中单独显示，但不计入电线过载。

| 导线（材料） | 1 kW 输送 50 格 | 1 kW 输送 100 格 |
| --- | --- | --- |
| 导电电线（铜） | 3.9% | 8.6% |
| 导电电线（铁） | 9.1% | 20.4% |
| 高负载电线（铁矿） | 23.4% | 47.4% |

详见 [电力系统设计](<docs/Mod玩法设计和修改/3. 电力系统设计.md>)。

### 房间：分级与环境

房间分为 T1 基础、T2 改善、T3 高级三级。T1（厕所、宿舍、食堂等）保持原版；T3 房间普遍要求**平均装饰度**，部分还要求**平均温度**，并给出更强的效果。

- **新增 16 个房间**：淋浴间、人造公园、工业区、医疗中心、舞厅、街机厅、海滨乐园、展览馆、风洞训练室、水疗室、茶歇室、任务控制室、地质研究室，以及航天发射场、星际货运站（眼冒金星 DLC）、数据机房（仿生人 DLC）。
- **改造 3 个原版房间**：私人卧室与宴会厅增加装饰度和温度条件，医院增加生命回复加成。
- **6 项新先天特质**（超级明星、电子竞技选手、海滨达人、冒险家、艺术家、火箭专家），持有者在对应娱乐房间获得额外加成。
- **13 种材料提高装饰度**（陶瓷、花岗岩、钢、玻璃等），建材选择会影响房间能否达标。
- 房间悬停卡会列出当前房间「可升级为」哪些房间以及还缺什么；娱乐房间还会列出对应的偏好特质。
- 人造公园是公园的替代方案：有足够野生植物满足原版公园或自然保护区时保持原版房间。

详见 [房间系统设计](<docs/Mod玩法设计和修改/4. 房间系统设计.md>)。

### 辐射：感生放射性

需要眼冒金星 DLC，并在开启辐射的星群中生效。材料长期处在强辐射中会自己带上放射性，离开辐射源后再慢慢衰减。

- 只有超过 **500 rads/周期** 的那部分辐射才会造成活化，一般只出现在研究反应堆、坠毁卫星、辐射粒子引擎等强辐射源附近；生活区和普通铀矿不受影响。
- **建筑与砖块**累积活化度，达到 10 rads/周期 后自身成为小范围辐射源，半衰期 10 周期。活化只增加放射，不影响建筑的其他属性。活化程度取决于建材：钢、铁最易活化，铅、塑料、木材最难。
- **液体、气体和天然格**带上原版的**放射性污染物**病菌，随流体流动、进入管道，可用病菌传感器检测、去污淋浴清除，半衰期 1 周期。放射性污染物优先于其他病菌，写入时会清除格子里原有的病菌。
- 活化物之间不会互相维持：拆掉真正的辐射源后，周围的放射性一定会衰减下去。
- **拆除活化建筑**时，一部分主建材（活化度 ÷ 1000，最多一半）变成带放射性污染物的核废料，拆掉重建不能代替衰减。
- 辐射的产生、传递、屏蔽和辐射病本身保持原版。

详见 [辐射系统设计](<docs/Mod玩法设计和修改/5. 辐射系统设计.md>)。

### 系统之间的联动

| 联动 | 效果 |
| --- | --- |
| 工业区 × 温度效率 | 工业区内工业建筑生产速度 ×1.2，与温度效率相乘 |
| 内置加热 × 电网 | 加热功率是真实用电，参与线路损耗与过载判断：金属精炼器生产加默认加热共 2400 W，已超过导电电线 2 kW 上限 |
| 建材 × 房间 | 高装饰度材料帮助房间达到平均装饰度门槛 |
| 高温工业 × 房间温度 | 高温建筑会加热所在区域，热量泄漏会破坏生活区房间的温度条件 |
| 辐射 × 医疗中心 | 医疗中心可以救治致命辐射病，但会留下后遗症 |

## 安装

1. 从本仓库的 [Releases](https://github.com/graduallyfar/ONI-Reform/releases) 下载最新版本的压缩包。
2. 解压到 Klei 数据目录的本地 Mod 文件夹，目录结构如下：

   ```text
   文档\Klei\OxygenNotIncluded\mods\local\MaterialOverhaul\
   ├─ MaterialOverhaul.dll
   ├─ mod.yaml
   ├─ mod_info.yaml
   ├─ build_profile.json
   └─ strings\zh.po
   ```

   「文档」目录被移到其他盘符时以实际位置为准。
3. 启动游戏，在「模组」菜单勾选「物尽其用 · Material Matters」并按提示重启。

注意：`strings\zh.po` 不能改名，否则界面会显示 `MISSING.STRINGS.*`。

## 分别开关四个系统

在游戏「模组」菜单中本 Mod 那一行点「**选项**」，可以分别开关工业、电力、房间、辐射四个系统，保存后**重启游戏**生效。默认全部开启。

- 关闭的系统回到原版行为；系统之间的联动只在两边都开启时出现（例如关闭房间后，工业区的 ×1.2 也随之消失）。
- 设置保存在 `mods\config\MaterialOverhaul\systems.json`，更新 Mod 时不会被覆盖。
- **在已有存档中途关闭某个系统**，该系统记在建筑上的数据（工业订单与磨损进度、建筑活化度、火箭飞行加成等）会在下次存档时丢失；复制人身上的新特质会暂时失效，重新开启后恢复。关闭前请先备份存档。

## 兼容性

- 游戏版本：需要 build `744825` 或更新。
- DLC：本体可以使用工业、电力、房间三个系统；眼冒金星 DLC 额外开放航天发射场、星际货运站和辐射系统；仿生人 DLC 额外开放数据机房。未启用的 DLC 内容会自动跳过。
- 存档：建议新开存档体验。加入已有存档或从存档中移除本 Mod 前请先备份；移除后，本 Mod 记在建筑上的数据会在下次存档时丢失。
- 其他 Mod：本 Mod 修改了工业建筑的生产与过热、电网结算、房间判定与房间大小上限、材料的建材类别与装饰度。修改同类内容的 Mod 可能冲突，目前没有针对其他 Mod 做过兼容测试。

## 已知问题与注意事项

- **首个公开版本**：各系统数值仍在调整，部分内容（尤其是后期房间与辐射）在长时间游戏中的表现还在测试中，欢迎反馈。
- **只有简体中文**：游戏使用其他语言时，本 Mod 的文字也显示中文。
- **自动化红信号只暂停生产，不停止预热和补热。** 想用智能电池在缺电时省电，需要另外切断这类建筑的供电。
- **高温工艺建筑会持续向周围放热**，复制人在环境温度超过约 72 ℃ 时会烫伤，建议给高温工业区做好隔热。
- **电网中出现无法计算长度的连接**（原版的虚拟连接）或未收录电导率的导线材料时，整张电网退回原版结算，电网信息卡会显示原因。
- **房间大小上限放宽到 2400 格**：原版超过 128 格的封闭区域会显示「太大」，现在会成为普通房间；超大型基地的性能尚未充分测试。

## 从源码构建

需要 .NET SDK 和本机安装的《缺氧》。复制 `MaterialOverhaul\local.props.example` 为 `local.props` 并填入自己的游戏目录，然后执行：

```powershell
dotnet build MaterialOverhaul\MaterialOverhaul.csproj -c Release
dotnet run --project tests\MaterialOverhaul.Tests\MaterialOverhaul.Tests.csproj -c Release
```

产物在 `_build/profiles/Combined/`。仓库不包含游戏程序集与反编译代码，也不打包游戏自带的 Harmony。
