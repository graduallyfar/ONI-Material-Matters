# 物尽其用 · Material Matters v1.0.4

相对 v1.0.3（`4f68079`）的全部改动。开发与验证记录见 [[V1.0.4开发计划]]。

**安装：** 下载 `MaterialMatters-1.0.4.zip`，解压到 `文档\Klei\OxygenNotIncluded\mods\local\`（覆盖旧的 `MaterialOverhaul` 文件夹），在游戏「模组」菜单启用并重启。需要游戏 build 744825 或更新。

## 房间

- **修复：偏好特质不会出现在新复制人身上。** 超级明星、电子竞技选手、海滨达人、冒险家、艺术家、火箭专家 6 项偏好特质，此前被放进了原版只供固定人物使用的特质池，随机生成的复制人抽不到。现在改为加入原版正面特质池，和原版正面特质一起随机抽取，稀有度暂定最低档。
- **特质列表显示对应房间**：这 6 项特质的名称下方新增一行说明（如「在舞厅获得额外加成」）。悬停说明会写出对应房间、持续时间（1 周期）和具体效果：士气 +4、压力每周期 −20%，另外按特质 +3 运动、机械、挖掘、建造、艺术或驾驶。
- 海滨达人和冒险家都对应海滨乐园。同时拥有两项时只按海滨达人结算，不叠加。

## 其他

- README 中的 Releases、Issues 链接改为新的仓库地址 `ONI-Material-Matters`。

## 从 1.0.3 升级的存档注意

- 特质在生成复制人时抽取，已有的复制人不会补发偏好特质；之后打印舱新出现的复制人才有机会抽到。
- 本版没有改动建筑端口、房间条件或存档数据格式，可以直接覆盖 1.0.3。建议加入已有存档前先备份。

## 验证状态

- 源码级测试和整合包的打包检查均通过。
- 游戏内验收仍在进行，偏好特质的出现频率与收益为测试初值，欢迎在 Issues 反馈。
