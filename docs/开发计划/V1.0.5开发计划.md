# V1.0.5 开发计划

2026-11-22，用户确认整合版版本号为 1.0.5。此前的兼容性修复验证包使用 1.0.4 构建版本号。

## 1. 问题与来源

2026-11-22，本机更新到 `U60-764025`（Steam Build ID `26798728`）。用户实测时，创意工坊 V1.0.4 的 `Patch_Overheatable_GetDescriptors` 抛出 `Undefined target method`，游戏记录模组加载失败并将其禁用。新版的建筑过热描述改由 `Overheatable.CollectDescriptors(GameObject, List<Descriptor>)` 写入调用方列表。原版 U59 使用返回列表的 `Overheatable.GetDescriptors(GameObject)`。

同次启动时 Better Info Cards 也因自身补丁失败被禁用。日志记录了主菜单初始化与随后的关停，进程退出原因未确定。

## 2. 处理范围

工业系统按原版程序集提供的方法选择对应的 Harmony 后置补丁。在原版过热温度描述后追加工作温区，沿用已有的显示条件、文字和数值。同步验证包里工业及整合版的补丁清单和计数。

整合版更新程序集版本、模组元数据、启动日志、README 和包检查的版本期望。工业、房间继续使用 0.2.2，电力使用 0.0.2，辐射使用 0.0.1。

## 3. 验证安排

- 对照 U59 参考代码和本机 U60 程序集，核对两种方法的签名与描述列表来源。
- 用源码级替身分别验证旧版和新版的工作温区后置处理，检查原版过热说明、条目顺序及名单范围。
- 使用 U60 程序集构建五个配置并执行包检查。用游戏自带 Harmony 核对整合版每个应装配的补丁是否能解析目标。
- 另行安排 [[整合版游戏测试清单]] 的游戏内复测，包括启动日志、两种工作温区显示路径与存档载入。

## 4. 待确认事项

游戏内复测待执行。

## 5. 实现与验证

- 工业独立版和整合版同时包含两种描述补丁。Harmony 优先选择 `CollectDescriptors`，旧版原版选择 `GetDescriptors`。两种后置处理共用工作温区生成逻辑。整合版把 Harmony 跳过的补丁类计入启动日志的跳过数。
- 对本机 U60-764025 和 ONI-ref 中的 U59-744825 运行工业描述签名检查，均通过。用各自的游戏程序集和随附 Harmony 对同一份整合验证包核对目标，两版均解析 110 个补丁类，另一版本专用的补丁类跳过 1 个。
- 五种配置使用 U60 游戏程序集构建通过。包检查 642 项、电力 IL 契约 10 项、房间契约 231 项及房间资源 55 项均通过。源码级测试通过 11,324 项断言，覆盖新旧后置处理、原版行及工作温区的顺序和名单范围。工业与整合版首次编译报告了原有 `KMonoBehaviour.Unsubscribe` 调用的两处过时警告。
- 代码经任务分支 `codex/u60-descriptors-fix` 合入 `combined-test`。游戏内复测待执行。
- 确认版本号后，用 U60 程序集重新构建五种配置并通过 642 项包检查及 11,324 项源码级断言。整合包清单与 `mod_info.yaml` 为 1.0.5，DLL 的程序集及文件版本均为 1.0.5.0。隔离检出中 52 项模拟部署检查通过，历史部署归档不受影响。
