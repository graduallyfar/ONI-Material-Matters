# V0.2.2 开发计划：材料过热百分比与深渊晶石建材

2026-10-16。用户要求过热损失采用原版速率、机械损失不变，将材料过热修正改为百分比，并让深渊晶石用于接受矿物原料的建筑。最新修订：**原有正向加成统一+60%，深渊晶石无加成；接受金属矿石的建材槽位也接受精炼金属，不更改版本号**。深渊晶石仍只加入矿物原料，不替代金属矿石。

## 1. 原版核实与范围

本轮定向反编译本机游戏 `E:\SteamLibrary\steamapps\common\OxygenNotIncluded\OxygenNotIncluded_Data\Managed\Assembly-CSharp.dll`，没有修改游戏程序集或只读参考目录。

- `Overheatable.StatesInstance.TryDoOverheatDamage`：每7.5 s节流触发1 HP伤害，`States.InitializeStates`以 `SIM_4000ms` 调度。实际扣血时刻取决于轮询，不能承诺恰好每7.5 s。当前Mod没有另设过热扣血流程，因此本轮保留原版实现，不新增扣血计时器。
- `BuildingHP.OnDoBuildingDamage / DoDamage`：按伤害事件的整数直接扣生命值。原有补丁只识别损坏原因及停止内置加热，不修改伤害量。
- `LegacyModMain.ConfigElements`：原版登记元素固定过热修正，例如花岗岩／火成岩／黑曜石 +15 K、金汞齐 +50 K、陶瓷／深渊晶石／钢 +200 K。Mod在这些原版条目建立后应用下述新规则。
- `AttributeInstance.GetTotalValue`：先合计基础项，再乘以 `1+倍率项之和`；过热属性基础使用K。`AttributeModifier.GetFormattedString`对倍率项原生显示百分比。
- `ElementLoader.Load` 在矿石预制件生成前建立元素及 `oreTags`；`MaterialSelector.GetValidMaterials` 按元素标签匹配类别。`PrimaryElement.OnSpawn` 将材料属性加入实例，支持旧档实例重建。
- 本机 `solid.yaml` 中深渊晶石 `Katairite` 原分类为 `Other`，熔点3695 K、硬度150、比热4、导热0.00001。本轮只追加 `BuildableRaw` 标签，保留原分类和物性；不追加 `Metal`、`RefinedMetal` 等类别。

- `BuildingConfigManager.RegisterBuilding`：配置类创建并设置建材后调用 `BuildingLoader.CreateBuildingComplete`，之后才创建施工与预览对象。新增建材扩展在这个入口前执行，让三类对象与建造菜单共用同一 `BuildingDef`。
- `MaterialSelector.GetValidMaterials` 以 `&` 分隔同一槽位的可替代类别，因此将 `Metal` 槽位扩展为 `Metal&RefinedMetal`，混合槽位保留其它选项；不修改原版共享类别数组，不新增槽位或改用量，也不让精炼金属变成矿石元素。

温控、订单、加热与磨损范围仍限定原三栋；材料百分比、矿物原料标签和精炼金属建材扩展适用于全局。金属精炼器、玻璃熔炉可用深渊晶石；岩石粉碎机可用金属矿石或精炼金属，不能用深渊晶石。纯精炼金属槽位不反向开放矿石。

## 2. 本轮采用的数值

按用户最新指示，原有正向过热加成统一为 **+60%**；深渊晶石移除过热修饰项，数值和材料面板均无该加成。原本没有加成的材料仍不新增加成；负向修正保留此前百分比。初稿按K等比例换算正向加成的方案已被本次指示取代，版本仍为0.2.2，游戏平衡未验收。

| 原修正 | 新百分比 | 代表材料 |
| --- | --- | --- |
| 正值 | +60% | 原有正向修正的材料，深渊晶石除外 |
| 深渊晶石原+200 K | 无 | 深渊晶石 |
| 无修正 | 无 | 砂岩、铝、钴等原本没有修正的材料 |
| −20 K | −2% | 铅 |
| −10 K | −1% | 泥土、污染沙 |

三栋的最终上限为 `U_K = 0.75 × 主材料熔点K × (1+主材料过热百分比)`，仍同时作为过热阈值、普通生产与内置加热上限；配方最佳区和建筑下限不变。三栋外沿用原版基础阈值，由原版属性系统应用新的百分比，不额外扩大温控范围或新增过热组件。倍率基于K，不能用摄氏数值乘算。

例如深渊晶石：`3695 × 0.75 = 2771.25 K = 2498.10 ℃`；花岗岩：`942 × 0.75 × 1.60 = 1130.4 K = 857.25 ℃`，现可完整覆盖炼铝最佳区。材料相变仍按原版；提高过热阈值不免除熔化。全部材料上限、高侧效率系数、交集回差、预热与覆盖矩阵，以及新增精炼金属候选已同步到 [[工业首发三建筑数值设计]]，不在这里复制整表。

机械磨损维持金属0.05、粉碎0.02、玻璃0.025 HP／实际生产秒，硬度达到25时不磨损；原有余额、维修、过热停热锁存均保持。
