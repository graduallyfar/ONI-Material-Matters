# 物尽其用 · Material Matters v1.0.5

本次更新修复《缺氧》11 月更新 `U60-764025` 上的模组加载问题。

## 工业

- 修复启用工业系统时，游戏因找不到旧的「工作温区」补丁目标而禁用本模组的问题。
- 已建成的工业建筑继续在效果区显示「工作温区」。U60 使用新的建筑描述接口，U59 继续使用原有接口。

## 安装

下载 `MaterialMatters-1.0.5.zip`，将其中的 `MaterialOverhaul` 文件夹解压到 `文档\Klei\OxygenNotIncluded\mods\local\`。如已手动安装旧版，请替换旧的同名文件夹。在游戏「模组」菜单只启用一份《物尽其用》，然后重启。游戏最低 build 为 `744825`。

## 验证状态

U59-744825 和 U60-764025 的工作温区接口及 Harmony 补丁目标已核对。五种构建、源码级测试、验证包检查和模拟部署检查均已通过。实际游戏启动、建筑信息卡和读档仍待复测。
