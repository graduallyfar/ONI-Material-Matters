# 整合版游戏测试清单

对应 [[V1.0.0开发计划]]、[[V1.0.1开发计划]] 与 [[V1.0.2开发计划]]：当前 Combined 包 `1.0.2`，工业、电力、房间、辐射同时启用。V1.0.1 修复项的复核见 §8，V1.0.2 见 §8.1，辐射（感生放射性）见 §9。本清单把各系统原有游戏验收项合并去重，按「开新档后先测什么」排列；原编号保留在「来源」列，便于回填各系统开发记录。

**全部未执行。** 部署、构建和替身测试不等于游戏验收通过；每条只有在游戏里实际看到结果后才能标通过。

## 0. 准备

- 使用专门测试存档（建议名 `MO-V1-Test`），不要在正式殖民地上测试；不要沿用 Industrial／Power／Room 独立包跑过的测试档当纯净基线。
- 每条记录：游戏 build、启用的 DLC、`build_profile.json` 的 `sourceCommit`、结果（通过／失败／未执行）与 `Player.log` 相关行。
- 建议先用**沙盒模式**和调试工具快速摆放建筑、改温度与给材料；涉及真实时长、读档和平衡的条目最后再用正常模式复核。
- 原版过程中出现的红字或 `MISSING.STRINGS.*` 都记为失败，附截图。
