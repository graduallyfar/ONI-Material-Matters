## 2. 代码改动

### 2.1 #23a、#23c：原版启停输入与取消新增输入

- `AutomationControlScope`：生产控制名单为原版已有逻辑控制输入的 28 栋（10 栋用电默认 (0,0)、18 栋 Config 写明），坐标只作原版位置记录；矿石洗涤器不在名单内。
- `Patch_BuildingLoader_CreateBuildingComplete`：`AddProductionControlPort` 改为 `CheckProductionControlPort`，不再往 Def 写输入端口；原版位置按 Def 输入列表或「用电默认 (0,0)」推定后核对。
- 文本：未新增或删除文本键（第一次修改新增的 `FORCEDRUN.TOOLTIP_ENABLE_NO_AUTOMATION` 已撤回，计数回到 103／294）。
- 测试：端口检查改为「原版有输入的 28 栋保持原位、矿石洗涤器没有输入、温区输出仍在占格内且不覆盖原版接口」。

存档影响（预期，未游戏验证）：Mod 不保存输入端口状态。旧版接到 Mod 输入口（如金属精炼器 (0,3)）的自动化线会留在原位但不再连接，需要改接到原版 (0,0)；未改接前建筑按未接线处理（允许生产）。矿石洗涤器原输入口 (0,2) 的线同样失效。

### 2.2 #23b、#24：温区输出改位与发电机取消输出

- `AutomationControlScope`：9 栋温区输出改位（油井在第二批）；新增 `WithoutOutput`（6 栋燃料发电机）与 `IsWithoutOutput`。
- `Patch_BuildingLoader_CreateBuildingComplete`：发电机不加输出并记一次说明；`MaterialOverhaulFab.Mode`、`Patch_LogicPorts_OnSpawn` 对发电机不报缺端口警告。
- `RunModeStatusItem`、`RunStatusText`：发电机默认模式提示改用新文本，不显示控制模式限制说明。文本 103→104（工业 89→90、整合版 294→295），`ProfileChecks` 同步。
- 测试：发电机无输出、9 栋截图位置、只有 4 栋与原版管道／电力接口同格。

存档影响（预期，未游戏验证）：改位的 9 栋、去掉输出的 6 栋发电机，旧档里接在原温区输出格的自动化线不再连接；改位建筑需改接，发电机读档后为默认模式。
