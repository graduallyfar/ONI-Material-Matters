## 4. 本轮代码改动

1. **整合版补丁顺序修正。** 工业补丁在 `Workable.GetEfficiencyMultiplier` 后置中记录最终倍率，`ComplexFabricatorWorkable.OnWorkTick` 用它把已缩放的 dt 还原成真实生产秒数计磨损；房间工作速度 +20% 补丁作用于同一方法。两者同为普通优先级时，按程序集类型顺序工业先执行，记录的倍率不含房间加成，工业区内复制人操作的批次建筑磨损会多计 20%。现给房间补丁加 `HarmonyPriority(Priority.HigherThanNormal)`，使其先乘入。只影响整合版；独立版行为不变。新增 3 项源码结构断言。
2. 核对了其余同目标补丁：`ComplexFabricator.ComputeWorkProgress`（工业按真实 dt 计磨损，与房间乘法顺序无关）、`ElementConverter.GetSpeedMultiplier`（工业按实际速度反解时间，已包含房间倍率）、`LegacyModMain.ConfigElements`（过热与装饰度分属不同属性）、`Db.Initialize`、`Game.OnCleanUp`，无需改动。
3. 版本改为 1.0.0（§2），默认构建模式改为 Combined；启动日志去掉「版本保持0.2.2」字样。
4. `Test-ProfileDeployment.ps1` 的 Combined 期望改为版本 1.0.0、文本 232 条（原 102 条为电力分支时期的旧值）。
5. **代码查错修复（2026-10-21，部署之后）。** 对照目标程序集查出的房间系统问题，均只改房间补丁，工业与电力未动：
   - 诊疗床恢复效果原先在 `Clinic.ClinicSM.Instance.StopEffect` 后置移除，而原版「未诊疗→已诊疗」内部切换也会调用它，护理员加成被立刻删掉，带着已诊疗效果回床的患者也会丢掉医院／医疗中心加成。改为 `Clinic.OnStopWork`（患者真正离床）时移除。
   - 顶替实验室的房间缺原版科研建筑 +10%（`Workable.OnUpdateRoom` 直接比较 `Laboratory`），顶替娱乐室的房间不生成闲聊格（`MingleCellTracker` 直接比较 `RecRoom`）。按用户此前推荐口径保留原版效果，两处均只对 `Beats` 明列的顶替关系补上。
   - 保持回差在拓扑重建时失效：原版每次重建都 `new Room`，新对象无类型。新增 `RoomRetention`，`RoomProber.ClearRoom` 前按格子记下旧类型，新房间判定取占多数的旧类型，`Refresh`／`UpdateRoom` 结束即丢弃。
   - 低问题：特质效果只在主设施完成工作时发放（与 `TriggerRoomEffects` 同一谓词）；`Game.OnCleanUp` 同时清空环境监视、快照与重建记录；货运站冷却加速限定 `on.cooldown.loop`。
   - 新增 `RoomPatchFixTests` 源码结构断言 12 项；`ProfileChecks` 房间补丁清单与 `--room-game` 契约同步。

代码中没有 TODO／NotImplemented；各开发记录的「未实现」项已在房间 §4.9 完成或明确不做，未发现设计已定但未实现的功能。
