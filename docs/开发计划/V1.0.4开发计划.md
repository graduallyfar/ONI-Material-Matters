## 3. 验证

- `dotnet build MaterialOverhaul\MaterialOverhaul.csproj -c Release`（默认 Combined）：0 警告、0 错误。
- 源码级测试：按约定命令 `dotnet run --project tests\MaterialOverhaul.Tests\...` 在本机得到 10910 项断言、**3 项失败**。3 项都在「开关配置：文件读写」，报错为 `DirectoryNotFoundException`（`SystemSwitches.Save` 没能在 `%TEMP%` 下建出目录），失败后同一测试类的后续断言也被跳过。
- 同一份构建用 `dotnet _build\tests\net10.0\MaterialOverhaul.Tests.dll` 运行：**11170 项断言、0 失败**。用生成的 `MaterialOverhaul.Tests.exe` 直接运行则复现这 3 项失败。单独调用测试程序集里的 `SystemSwitches.Save`、单独运行开关测试、按原顺序依次运行前面全部测试类后再保存，也都成功。因此判断失败来自本机用 exe 启动时的文件系统限制，与代码无关；Defender 受控文件夹访问已确认关闭，具体原因未查明。这 3 项在 `main`（1.0.2）上同样失败；`v1.0.3` 之后没有改动 `SystemSwitches.cs` 或 `SystemSwitchTests.cs`。
- 未部署，未启动游戏。偏好特质的抽取频率与说明行仍待游戏内验收（[[整合版游戏测试清单]] C45）。
