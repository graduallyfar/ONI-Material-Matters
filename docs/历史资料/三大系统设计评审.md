## 0. 结论先行

1. **总体评价：设计思路很好，执行的严谨程度在 ONI 模组里少见；最大的风险不在设计，而在验证太少。** 三个系统都还没有一条游戏内验收是通过的，设计已经跑到验证前面很远了。
2. **电力系统最贴合你的总纲**：它让线材的材料第一次真正参与计算（原版里线材材料基本只影响装饰度和过热）。主要问题是玩家看不懂、算不出损耗，模型里还有一两处和直觉相反的地方。
3. **工业系统机制最扎实，但复杂度最高。** 熔点、比热、导热、硬度四个原版属性都被用上了，正好落在「材料参与运算」上。风险在于玩家要同时理解太多概念；而且「排程就是热管理」这个核心卖点，在界面上几乎看不出来。
4. **房间系统离总纲最远，数值门槛偏高。** 平均装饰度要求普遍在 +80～+120，而原版复制人装饰感知的最高档就是 120（已核实）。另外回报大多是同质的「士气 +2」，科研和航天几间更是和材料无关的纯加成。
5. **三个系统之间最好的配合**是「工业加热功率 → 高负载线路损耗」和「建材 → 过热上限、硬度、装饰度一材三用」。**最需要处理的冲突**是工业区装饰门槛和工业建筑本身的负装饰，以及陶瓷、黑曜石跨系统叠加成通吃材料。
6. **房间数值里有一部分是我（Claude）10-20 代定的**，见 §3.1 的对照表。其中「医疗中心自动隔离 → 改成优先入院」改变了你原设计的含义，最需要你拍板；特质数值我可能压得太低了。

## 1. 工业（建筑）系统

### 1.1 亮点

- **闭环清楚**：主材熔点决定上限 U，U 决定配方最佳区能否达到；温度决定效率，比热决定预热成本，导热决定保温，硬度决定磨损，订单顺序决定调温次数。每个原版属性都有明确的落点，而且不需要新造属性。
- **「能用但有代价」落实得好**：默认模式在低温下也能低效生产，控制模式只在交集内生产，强制运行可以越界但要承担伤害。没有一种材料被硬性禁止，符合原则 1、2、6。
- **边界规则非常完整**：暂停时保留进度、不重复投料、磨损的小数余额跨读档保存、过热停热保护只有完全维修才解除、机械和过热两种损坏原因并存。这些是 ONI 模组里最容易出 bug 的地方，你都事先写清楚了。
- **连续设备和发电机的同比缩放很聪明**：投入和全部产物乘同一个 η，投入产出比不变；发电机降低的是每秒功率，每 kg 燃料的电量不变。原版的配比都不会被破坏。
- **尽量复用原版**：`LogicOperationalController` 的未接线默认放行、`Overheatable`、`Repairable` 的维修成本、`ElementConverter` 的速度倍率都直接拿来用，兼容性好。

### 1.2 与原版玩法的契合度

- **有新意，但和原版习惯是反着来的。** 原版玩家对金属精炼器的经验是越冷越好，整套冷却回路都在想办法把热量带走。现在要求本体保持在 450–1600 ℃，玩法从排热变成「保温 + 排热」并存，这是好的反转。
- **推断风险：复制人操作的高温建筑。** 精炼器、玻璃熔炉、分子熔炉都需要复制人站在旁边操作。本体达到几百摄氏度时，周围的气体会被加热，最后很可能只剩「真空隔热 + 气压服操作」一种解法。气压服本身又需要精炼金属，对早中期是一道陡坎。建议专门做一项验收：默认 1200 W、普通房间里，精炼器旁边的气温在一个周期后是多少。
- 注热倍率 M = 100 的意思是 1 W 电约等于 100 W 热。听起来很高，但据记忆原版液体加热器的电热倍率比这还高得多，所以和原版并不冲突。

### 1.3 平衡与复杂度风险

| 问题 | 说明 | 依据 |
| --- | --- | --- |
| **玩家要理解的概念太多** | 建筑下限 L、材料上限 U、配方最佳区、两侧效率底值、默认/控制模式、强制运行、加热滑条、补热回差、硬度磨损、过热停热保护、双损坏原因，29 栋共用同一套规则 | 设计文档 |
| **低风险建筑的收益和认知成本不对等** | 净水器、藻类蒸馏器、发电机、洗涤器的低侧底值都在 0.80–0.90，20 ℃ 时损失只有 0–15%，却同样多出端口、模式和状态栏 | §2.8.4–2.8.6 |
| **模式由「输出端口是否接线」隐式决定** | 设计很巧妙，但玩家很难自己发现；只接了输入端时也不会进入控制模式 | §2.1.2 |
| **「排程即热管理」在界面上看不出来** | 底层是有序订单（炼铜→炼铁→再炼铜），但额外的订单侧屏已经移除，玩家只看得到原版的「当前安排 / 下一安排」和合计数量，既看不到也没法调整顺序 | §2.3.5 |
| **统一 +60% 形成二元断崖** | 有原版正向加成的材料一律 ×1.6，没有的 ×1.0，比如花岗岩 U 是 857 ℃，砂岩是 627 ℃；原版加成大小的差别被抹平了 | §2.0.3 |
| **U 可以高于材料真实相变点** | 例如铜 U = 1355 ℃，但铜在约 1084 ℃ 就熔化了；信息卡上的「过热温度」比熔点还高，玩家会困惑（文档已承认 U 不防熔化） | §2.8.8.3 |
| **陶瓷和黑曜石通吃** | 陶瓷：U 2274 ℃，覆盖全部配方；导热 0.62 利于保温；硬度 50 不磨损；房间系统还给它 +25% 装饰度。黑曜石：U 3327 ℃、硬度 200、比热 0.2，文档已承认它占优。剩下的取舍基本只有「比热 → 预热时间」这一项，这和原则 4 有冲突 | §2.6.9 |
| **硬度系统存在感低** | 要求硬度统一为 25，大多数金属矿石和精炼金属都达标，磨损只会落在砂岩、沉积岩、金、铅、锌这类少数软材料上，而且多集中在早期 | §2.6.10、§2.8.7 |

### 1.4 建议

1. 订单顺序至少要做成**只读可见**，比如在状态悬停里列出接下来 3 笔订单。否则排程这一层设计基本等于不存在。
2. 输出端口的悬停说明写明「接线即进入控制模式」。状态栏已经会显示当前模式，但玩家还需要知道怎么切换。
3. 显示的过热温度改成 `min(U, 实际相变点)`，或者在悬停里提示「材料会先熔化」。
4. 对低惩罚建筑（底值 ≥ 0.85）考虑一个**简化档**：不显示模式和端口，只保留温度效率。
5. 重新看一下统一 +60%：可以按原版加成大小分成 2–3 档，例如 +30/+60/+90，把原来的材料梯度还回来。

## 2. 电力系统

### 2.1 亮点

- **最符合总纲**：新增的电导率让线材的材料第一次真正影响结果，而且没有引入电压、电流，复杂度控制得住。
- **体验曲线有设计**：前期接线随意、中期开始感受到浪费、后期主动分区，公式里的 `w(P)` 让基础损耗和长度惩罚随负载切换主导地位，这个思路很好。
- **结构上很稳**：逐对象按最短实际线格计算，变压器作为分割点，电池充放电分开记账；遇到未知材料或虚拟连接时整网回退原版并显示原因，不会默默按零损耗处理；参数单调性约束也提前想到了求解时的需要。
- **契合原版习惯**：原版玩家本来就会用变压器分区来保护电线，损耗给了分区第二个理由。

### 2.2 首轮测试初值下的实际损耗（我按 `PowerBalance.cs` 的参数算的）

| --- | --- | --- | --- |
| 电线（铜，σ=1） | 0.6% / 2.5% / 7.2% | 0.6% / 3.7% / 14.9% | 1 kW：0.6% / 3.7% / 15.1% |
| 电线（铁矿，σ=0.12） | 1.7% / 6.8% / 20.3% | 1.5% / 9.3% / **41.2%** | — |
| 导线（铜） | 0.7% / 2.7% / 6.7% | 0.5% / 2.9% / 10.2% | 2 kW：0.5% / 3.0% / 11.2% |
| 高负载电线（铁矿） | 5.8% / 19.5% / 39.7% | 2.9% / 10.5% / 23.6% | 4 kW：1.5% / 6.0% / 15.6% |

看下来，前期短线确实基本无感，长距离矿石线材的惩罚很重，高负载线接小设备也确实很贵，和设计意图一致。

### 2.3 风险

1. **`w` 用的是单个接收者的功率，不是线段上的实际流量。** 一条 20 kW 的主干给 40 台 500 W 设备供电时，每台设备都按自己的 500 W 计算，主干上「流量大所以单位损耗低」的效果不会出现，只有经过变压器聚合以后才会出现。这在模型上是自洽的，但和玩家「主干粗就省电」的直觉相反。建议在文档里明确写成**有意设计**，并在界面上解释；否则玩家会觉得高负载线不好用。
2. **变压器会截断指数惩罚。** 长度惩罚按每条路径单独计算，路径在变压器处截断，所以每隔 N 格放一个变压器，就能把指数项变成线性。据记忆原版变压器本身没有损耗，那么「变压器中继链」很可能成为最优解。如果这不是你想要的，可以给变压器一个固定损耗。
3. **玩家看不到自己该优化什么。** 公式有 14 个参数，信息卡只显示整网损耗。建议在用电器信息卡上显示「到最近电源 N 格、本设备损耗 x%」。没有这一行，这个系统对玩家来说就是个黑箱。
4. **独立版和整合版的平衡不一样。** Power 独立版不含「金属矿石槽位开放精炼金属」，普通电线和高负载电线只能用矿石，σ 在 0.10–0.45 之间。整合版里可以用铜（σ=1），损耗相差 2–4 倍。所以平衡结论必须在 Combined 里验收，独立版的结论不能直接搬过去。
5. **「最近电源」把电池和发电机放在同一顺序里。** 原版玩家的直觉是发电机优先、电池补缺；现在近处的电池会先放电，再由远处的发电机给它充电。这给电池摆放带来了新含义，算好事，但需要提示玩家。
6. **损耗不转成热，能量凭空消失。** 0.0.2 这样处理没问题。以后如果把损耗变成电线发热，会和工业的热管理形成很强的联动，但热平衡和性能的代价都很大，可以留作远期选项。
7. **性能**：每个对象都要算最短路径。大殖民地上，电线增减时的缓存重建要专门测。

**我对自己代定值的回看：**

- **特质 +4 / −20% / +3 可能压得太低。** 当时的理由是「特质效果不应强过专用房间」。但这些特质是随机抽到的，拥有的复制人很少，回报本来就小概率；再下调，玩家几乎感觉不到。建议恢复你的 +5 / −30% / +6，至少把士气改回来。
- **医院 +25%、护理员 +25%、水疗 −40%** 只是为了拉开梯度，理由一般。改回你的值没有任何技术代价，只需要改 `RoomEffectCatalogue.cs` 和 PO 文本。
- **「自动隔离」改成「优先入院」是对设计含义的改动**，不只是调数值。我当时担心强制禁足会把复制人困死或饿死，但你原文明确写了「可以使用医院内的餐桌与厕所」，可见你考虑过封闭生活的场景。这一条最需要你拍板。
- **辐射救治不耗材料、不加时长，偏慷慨。** 你原设计里的代价只有永久运动 −6；如果觉得太便宜，可以加一次配药桌的药品消耗。
- 回差和 600 s 持续时间是工程性的决定，没有玩法含义，可以保留。

### 3.2 亮点

- **T1 不动**，保住了开局难度；改造集中在 T2、T3，路线清楚。
- **平均装饰度和平均温度作为房间条件**，把装饰材料和温控工程变成了经营目标，这是房间系统里最贴合总纲的部分。
- 娱乐室分化出 7 个专精房间，给原版那些没什么存在感的娱乐设施找到了升级出口。
- 原版房间优先、显式 Beats 名单、改造房间降级后仍能升回，这套仲裁规则很稳。

### 3.3 问题

1. **装饰度门槛过高（已核实依据）。** 原版 `DecorMonitor.MAXIMUM_DECOR_VALUE = 120`，复制人装饰感知的档位边界是 −30 / 0 / 30 / 60 / 90 / 120。按这个标准：
   - 展览馆、宴会厅要求**全房间平均 ≥ +120**，等于每一格都处在原版最高档；
   - 舞厅、街机厅、茶歇室要求 ≥ +100，医疗中心、私人卧室、水疗室、海滨乐园、风洞要求 ≥ +80；
   - 工业区要求 ≥ +60，而且是在一屋子带负装饰的工业机械里。
   - **推断**：大多数玩家达不到这些门槛；就算达到了，复制人自己的装饰感知已经在拿原版最高档的士气，房间再给的「+2」会显得多余。
2. **回报偏小，而且同质。** 7 间娱乐升级房的普通效果都是士气 +2，条件也几乎一样：专属设施 + 装饰建筑 + 20–26 ℃ + 装饰 ≥80～120。它们之间的差异主要靠特质，而特质很稀有。
3. **新增特质偏离了你自己定的边界。** V3.0.0 §1.2 写了「不新增整套特质生成系统」，原则 5 也写了「不增加新的纵向玩法」。把 6 个 `MO_*` 特质塞进原版先天特质池，会影响所有新复制人的抽取结果。
4. **温度带重复。** 6 间房间用的都是 20–26 ℃，只有 6 ℃ 宽。推断：ONI 常见的居住区温度大约在 20–30 ℃，统一用这一个窄带会让解法单一。水疗室的 26–50 ℃ 是个好例外，值得多做几种不同的温带。
5. **人造公园可能让原版公园降级（已核实代码）。** `MO_ArtificialPark` 的 Beats 是 `{Park, NatureReserve}`，Priority 为 1，和原版同级。一个有 ≥4 株植物、12–64 格的原版公园或小自然保护区，会被判成人造公园，拿到 +2，同时失去原版的 `RoomPark` / `RoomNatureReserve` 效果。这两个效果确实存在；具体数值我在快照里没找到，据记忆高于 +2，需要核对。建议让人造公园不再顶替原版公园，只在原版条件不满足时成立；或者要求必须是非野生植物。
6. **科研和航天四间系统性最弱。** 任务控制室、地质研究室、航天发射场、星际货运站都是纯加成，和材料没有关系；但实现成本最高，要碰大量私有入口，还有不写进存档的跨阶段状态。
7. **大房间改动是全局的。** `maxRoomSize` 从 128 提高到 2400 会影响所有开放区域：原来「太大」不算房间的区域，现在会变成中立房间。养殖拥挤度和性能都要专门测。

## 4. 系统之间的配合与冲突

### 4.1 配合（值得保留并强化）

1. **工业加热和电力损耗**：一栋精炼器最高需要 1200 + 4000 = 5.2 kW，正是电力系统想惩罚的「大功率长距离」场景。重工业区自然会用上高负载线和变压器分区。这是三个系统里最好的联动。
2. **一材三用**：建材同时决定 U（工业）、硬度（工业）和装饰度（房间 M01）；做导线时还决定电导率（电力），前提是整合版开放了精炼金属槽位。材料选择的深度就来自这里。
3. **工业区 +20% 和温度效率相乘**，磨损按真实秒数累计，所以工业区还会降低单位产品的磨损，逻辑自洽。

### 4.2 冲突或摩擦

| 冲突 | 说明 | 建议 |
| --- | --- | --- |
| 工业区装饰 ≥60 vs 工业建筑的负装饰和高温 | 工业区要漂亮，工业机械本身扣装饰，本体还要几百摄氏度 | 工业区门槛降到 0～+20，或者改成「装饰建筑数量」 |
| 补热、强制时 2400 W 超过导线 2 kW | 控制模式补热或强制加热时，生产 1200 W 加默认滑条 1200 W 就是 2400 W，超过原版导线 2 kW 的容量；用导线接精炼器的老档会过载 | 在加热滑条的悬停里提示总功率和线材上限，或者把默认滑条降到 800 W |
| 陶瓷跨系统通吃 | 覆盖全部温区、保温好、不磨损，还有 +25% 装饰 | 重看 +60% 分档；陶瓷的装饰加成可以只给生活类建筑 |
| 独立版的平衡结论不通用 | Power 独立版只能用矿石做电线，Industrial 独立版没有线损 | 平衡验收统一在 Combined 里做 |
| 工业区和原版发电厂互斥 | 原版优先，所以发电机不能放进工业区；这本身合理，但玩家需要知道 | 在房间说明里写一句 |

## 5. 最值得改进的几点（按优先级）

1. **先冻结范围，在 Combined 里正常玩 20–30 个周期。** 三个系统的游戏内验收都还是 0，继续往下设计，是在没验证过的地基上加楼层。建议这一轮只记录体感问题，不追求逐条验收清单。
2. **房间装饰门槛整体下调，并拉开回报差异**：参考原版档位，T2 定在 +20～+30，T3 定在 +40～+60。同时修掉人造公园顶替原版公园的问题。
3. **工业系统的可见性**：订单顺序做成可见，写明端口接线如何切换模式，过热温度显示为 `min(U, 相变点)`，低惩罚建筑提供简化档。
4. **电力的可读性**：在设备信息卡上显示「路径长度 + 损耗%」；文档里明确 `w` 按接收者功率计算是有意设计，并决定变压器中继链是否是你想要的玩法。
5. **重看统一 +60% 和陶瓷、黑曜石统治问题**，把原版加成大小的差异以分档的形式还回来。
6. **把房间的科研和航天四间往后放**，先把生活、娱乐、医疗、工业区这几条和材料、环境相关的线做扎实。
7. **请你拍板我代定的三处**：医疗中心是「隔离」还是「优先入院」；特质数值是否恢复你的 +5 / −30% / +6；医院、护理员、水疗是否改回你的原值。
