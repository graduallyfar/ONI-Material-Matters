# 4. 房间系统设计

本篇是房间系统的分设计文档，说明房间分级改造、新增加成、装饰度修改与房间温度判定，包含复制人特性相关的房间效果。系统定位见 [[ONI Reform 总体设计#4. 房间系统]]。

**状态：P1 基础实现与部分士气／压力／生产效果已落地，其余效果未实装。** 房间类型、构成要求与加成是本轮设计定案；代码已实现房间独立模式、16 个新增房间的构成与环境条件、私人卧室／宴会厅的附加条件、平均装饰度／平均温度判定，以及人造公园与七间娱乐房间的普通士气 +2、淋浴间压力 −10%、水疗室压力 −50%、茶歇室压力 −30%、宴会厅追加压力 −10%、工业区与数据机房的批次／无人／连续转换速度 +20%（持续时间、压力与生产倍率的工作口径见开发计划）。属性、特质专项、医疗、科研、航天等效果尚未接入，也没有游戏验收。原版房间的基础行为与装饰度感知算法保持不变；实现工作取值见 [[V3.0.0开发计划#4.7 本轮实现口径（待确认项的工作取值）]]。

开发范围、原版接入依据、分阶段任务与验收清单见 [[V3.0.0开发计划]]。下列已列明的要求与数值继续作为设计依据；§4.4 及开发计划中展开的未决边界须在对应模块实施前确认，不能把文档整理完成记为代码完成。

原版现有房间类型：杂间、公共厕所、卫生间、宿舍、豪华宿舍、私人卧室、食堂、餐厅、宴会厅、厨房、按摩诊所、医院、发电厂、温室、畜舍、实验室、娱乐室、公园、自然保护区。

## 4.1 房间等级划分和修改

开发阶段对房间系统设置 T1–T3 三个等级：基础房间、改善房间、专业高级房间。**低等级房间保持现状，以维持游戏开局的难度**；改造集中在 T2、T3。

### 4.1.1 T1 等级　基础房间

类型：公共厕所、卫生间、宿舍、食堂。

这些房间系统的效果不变，加成不变。

### 4.1.2 T2 等级　中级房间

类型：豪华宿舍、餐厅、厨房、按摩诊所、医院、发电厂、温室、畜舍、实验室、娱乐室、公园、自然保护区、淋浴间（新增）、人造公园（新增）。

对已经存在的房间系统保持不变，只对新增房间进行更改。

所有高级房间增加装饰度要求，拥有最低装饰度限制。

## 4.2 装饰度修改

### 4.2.1 装饰度加成

对部分建筑或材料的装饰度加成进行数值修改和增加。

**修改：**

| 材料 | 装饰度 |
| --- | --- |
| 陶瓷 | +25% |
| 花岗岩 | +25% |

**新增：**

| 材料 | 装饰度 |
| --- | --- |
| 铝矿 | +10% |
| 黄铁矿 | +10% |
| 钢 | +20% |
| 导热质 | +20% |
| 铝 | +20% |
| 贫铀 | −50% |
| 石墨 | +20% |
| 玻璃 | +20% |
| 羽毛纤维 | +10% |
| 珍珠 | +10% |
| 粘胶木材 | +50% |
| 交合板 | +10% |

### 4.2.2 装饰度计算

复制人拥有一个装饰度感知值，通过该感知值获得士气 buff，该值是一个周期平均值；**这个数值和计算方法不改变**。

房间装饰度按**平均装饰度**判定，即房间内所有格子的装饰度加上下方一格建筑的装饰度之和，再取平均。

## 4.3 房间温度设计

房间温度要求采用**房间平均温度**，与建筑本体温区（[[2. 建筑系统设计#2.1 工作温度范围]]）是两套独立判定：建筑温区约束单栋建筑，房间温度只作为房间条件的判定依据，不改变建筑的生产许可或温度效率。

## 4.4 未决事项

1. 房间等级的完整分类尚未逐项确认：4.1.3 的类型列表与新增房间清单需要对齐（例如公园、自然保护区同时出现在 T2/T3 列表中）。
2. 各房间的判定优先级、与发电厂等原版房间加成的叠加方式未定。
3. 工业区「生产效率 +20%」与建筑系统温度效率（[[2. 建筑系统设计#2.6.6 温度效率曲线：系数与全部边界]]）的相乘方式、是否受强制运行与暂停影响未定。
4. 装饰度加成是材料属性修改还是建筑属性修改、与建筑系统硬度／温区取主建造材料的口径是否一致，需要在实现前确认。
5. 房间温度与温控建筑的联动方式未定；本章不改变 [[2. 建筑系统设计]] 的温区、效率与加热规则。

上述问题及实施调查发现的具体缺口统一跟踪于 [[V3.0.0开发计划#3. 实施前需要确认的规则]]，包括 T3 未给装饰阈值的房间、平均环境采样、效果触发与持续时间、特质定义、医疗隔离、科研和发射效果结算。待确认项不会因原版存在相近机制而自动定案；确认后应先更新本篇有效定义。
