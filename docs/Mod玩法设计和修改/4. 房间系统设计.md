# 4. 房间系统设计

本篇说明房间系统的全部玩法规则与数值：房间分级、平均装饰度与平均温度的判定、房间之间的顶替关系、每个房间的构成要求与加成、偏好特质和材料装饰度。系统定位见 [[ONI Reform 总体设计#4. 房间系统：分级与环境]]。

## 4.1 分级总览

房间分为三级。**低等级房间保持原版，维持开局难度**；改造和新增集中在 T2、T3。

| 等级 | 房间 |
| --- | --- |
| T1 基础 | 公共厕所、卫生间、宿舍、食堂（全部保持原版） |
| T2 改善 | 原版：豪华宿舍、餐厅、厨房、按摩诊所、医院★、发电厂、温室、畜舍、实验室、娱乐室、公园、自然保护区；新增：淋浴间、人造公园 |
| T3 高级 | 改造：私人卧室★、宴会厅★；新增：工业区、医疗中心、舞厅、街机厅、海滨乐园、展览馆、风洞训练室、水疗室、茶歇室、任务控制室、地质研究室、航天发射场、星际货运站、数据机房 |

★ 为在原版基础上改造的房间。T3 房间普遍要求最低平均装饰度，部分还要求平均温度。航天发射场、星际货运站需要群星（Spaced Out）DLC，数据机房需要仿生人 DLC；DLC 未启用时这些房间不出现。

## 4.2 通用规则

### 4.2.1 平均装饰度

房间装饰度条件看的是**房间平均装饰度**：房间内所有格子当前装饰度的算术平均。

- 每格装饰度已经包含周围建筑、艺术品和光照对该格的贡献（原版装饰度覆盖图上看到的值）。
- 被实心砖块等占据的格子按 0 计入，因此房间里砌墙、堆实心建筑会拉低平均值。
- 复制人自身的装饰度感知（士气来源）和计算方法**不改变**，只是房间判定改用平均值。

T3 房间按用途分两档门槛（V1.0.1 下调）：生活与娱乐房间 +50～+80，正常装修（画、雕像、植物、光照和 §4.9 的高装饰材料）即可达到；工业区、任务控制室、地质研究室这类功能房间往往建在基地之外，只要求 +20。航天发射场、星际货运站、数据机房没有装饰度要求。

### 4.2.2 平均温度

房间温度条件看的是**房间平均温度**：房间内所有非真空格子温度的算术平均（按格平均，不按质量加权），真空格不计入；整个房间都是真空时温度条件判为不满足。

房间温度只用于判断房间类型，与建筑本体的工作温区（[[2. 建筑系统设计#2.2 工作温区]]）是两套独立判定，互不影响。

### 4.2.3 保持回差

为避免环境值在阈值附近来回跳，**已经成立的房间**在重新判定时条件放宽：

- 平均装饰度下限放宽 5 点（例：要求 +65 的舞厅，降到 +60 以下才失去）。
- 温度条件两端各放宽 1 ℃（例：20–26 ℃ 的房间，保持时 19–27 ℃；数据机房「低于 20 ℃」保持时为低于 21 ℃）。
- 新建立房间（从其他类型或中立房间升级）仍按原阈值判定。
- 在房间里建造、拆除建筑或改动墙体后，房间会重新划分，但只要还是原来那个房间，回差照样有效。
- 私人卧室、宴会厅的新增条件同样适用。

平均装饰度和平均温度每隔一段时间重新采样，房间类型变化后才重建房间。

### 4.2.4 顶替关系

- 新房间只会顶替**明确列出**的原版房间（下表），其他情况保留原版结果。例如房间里同时有厕所和淋浴，保持原版卫生间，不会变成淋浴间。
- 同时满足多个新房间时，取优先级最高的一个。
- 顶替房间继承原版房间的作用：顶替实验室的房间**仍算实验室**，其中的研究站、望远镜、航天指挥站、地质调谐仪照常运作并保留原版实验室 +10% 工作效率；顶替娱乐室的房间**仍算娱乐室**，复制人休息时间可以在里面闲聊。

| 新房间 | 顶替的原版房间 |
| --- | --- |
| 人造公园 | 公园、自然保护区 |
| 医疗中心 | 医院 |
| 舞厅、街机厅、海滨乐园、展览馆、风洞训练室、水疗室、茶歇室 | 娱乐室 |
| 任务控制室、地质研究室、数据机房 | 实验室 |

注意：人造公园会顶替满足条件的公园和自然保护区，顶替后不再获得原版公园／自然保护区的士气效果，只有人造公园的 +2。

改造房间（私人卧室、宴会厅）的新增条件不满足时，按原版规则降级为下一档房间（私人卧室 → 豪华宿舍；宴会厅 → 餐厅或食堂）。

### 4.2.5 房间大小

原版房间最大只识别 128 格；为容纳工业区（1000 格）和航天发射场（2400 格），识别上限放宽到 2400 格。因此 129–2400 格的封闭区域会显示为普通的中立房间，而不是原版的「太大」。各房间自己的格数条件照常生效。

### 4.2.6 效果的触发与持续

| 效果类型 | 何时获得 | 持续 |
| --- | --- | --- |
| 士气、压力类（淋浴间、人造公园、娱乐房间、宴会厅） | 使用房间的专属设施后（人造公园与原版公园一样，进入房间即触发） | 1 周期（600 s），再次使用刷新 |
| 偏好特质加成 | 特质持有者进入对应房间时；在房间内完成工作也会刷新 | 1 周期 |
| 生命回复（医院、医疗中心、护理员） | 患者在诊疗床开始治疗时 | 直到患者离开诊疗床；治疗过程中的状态切换（例如医生完成诊疗）不会中断 |
| 生产效率（工业区、数据机房、任务控制室、地质研究室） | 建筑位于该房间内时 | 随房间存在，实时生效 |

**压力百分比的含义：** 「压力 −20%」作用在压力变化速率上：压力上升时上升速度降低 20%，压力回落时回落速度提高 20%。

### 4.2.7 信息显示

- 所有房间（含原版房间与中立区域）的悬停信息卡都显示**平均装饰度**；有温度条件的房间另显示平均温度。
- 房间概览图例与悬停卡第一行，按原版写法给出一句效果简述（例如「- 士气加成」「- 生产加速」）；房间提示只写效果，构成条件由「需求」列表显示。
- 主条件写专属设施的建筑名（例如「至少 1 个航天指挥站」），不写房间名。
- 位于房间内并获得加成的建筑，在状态栏显示一条「房间名：加成」（工业区的工业建筑、数据机房的数据挖掘中心、任务控制室的航天指挥站、地质研究室的调谐仪、航天发射场的发射平台、星际货运站的星际物流发射器、医院／医疗中心的诊疗床）。矿石洗涤器不受工业区加成，不显示。
- 群星火箭在本次飞行受到任务控制室助推或航天发射场加成时，状态栏显示「房间加成：速度 +N%」，悬停列出来源。
- 状态只写公开的基础加成；科学家翻倍、偏好特质等附加条件不在状态和详情里标出。

## 4.3 建筑分类

房间条件里用到的建筑类别：

| 类别 | 包含 |
| --- | --- |
| 工业机械 | 原版「工业机械」标签的建筑（「无工业机械」条件使用原版判定） |
| 工业建筑 | 本 Mod 定义，用于工业区：金属精炼器、玻璃熔炉、岩石粉碎机、分子熔炉、化学精炼厂、窑炉、漂白石料斗、钻石压机、铀素离心机、硫化器、胶合板压机、泥浆分离器、爆破弹组装机、原油精炼器、聚合物压塑器、乙醇蒸馏器、肥料合成器、藻类蒸馏器、氧石精炼炉、净水器、脱盐器、油井、矿石洗涤器（不含发电机，发电机属于发电厂） |
| 高级娱乐建筑 | 点唱机器人、游戏机台、沙滩椅、机械冲浪板、垂直风洞、桑拿浴室、热水浴缸、咖啡机、汽水机、饮水机、榨汁机 |
| 生活建筑 | 床、豪华床、诊疗床、餐桌、多人餐桌、户外厕所、冲水厕所、壁挂厕所，以及全部高级娱乐建筑 |
| 科学建筑 | 原版「科学建筑」标签的建筑 |
| 装饰建筑 | 原版「装饰」标签的建筑（画、雕塑、植物盆等） |
| 光照设备 | 正在发光的灯（关掉的灯不算） |
| 存储设备 | 任何带储存功能的建筑 |
| 杰出艺术品 | 艺术品当前品质为「杰出」 |
| 藏品展示 | 基座上正在展示物品 |
| 植物 | 房间内的植物，分枝不计 |

「无其他高级娱乐建筑」指：除本房间的专属设施外，房间里不能有其他高级娱乐建筑。「除××外无其他科学建筑」同理。

## 4.4 T1 基础房间

公共厕所、卫生间、宿舍、食堂：要求与效果全部保持原版。

## 4.5 T2 改善房间

原版 T2 房间除医院外保持原版。

### 4.5.1 医院（改造）

- 构成要求：保持原版。
- 加成：患者在医院的诊疗床接受治疗期间，**生命回复速度 +25%**。与医疗中心的回复加成互斥（同一张床只会在一种房间里）。

### 4.5.2 淋浴间（新增）

- 构成要求：至少一个淋浴间；无工业机械；12–64 格。
- 加成：使用淋浴后**压力 −10%**，持续 1 周期。
- 房间里同时有厕所时保持原版卫生间／公共厕所，淋浴间只适用于独立的淋浴区。

### 4.5.3 人造公园（新增）

- 构成要求：至少 4 株植物；至少一个公园标识；无工业机械；12–64 格。
- 加成：**士气 +2**，持续 1 周期。
- 会顶替公园和自然保护区（见 §4.2.4）。

## 4.6 T3 高级房间：改造

### 4.6.1 私人卧室

- 构成要求：原版要求不变；平均装饰度 ≥ **+50**；平均温度 **10–40 ℃**。
- 加成：保持原版。

### 4.6.2 宴会厅

- 构成要求：原版要求不变；至少一个光照设备；平均温度 **20–26 ℃**；平均装饰度 ≥ **+80**。
- 加成：
  - 原版宴会厅效果的士气统一为 **+6**；
  - 使用宴会厅餐桌后追加 **压力 −10%**，持续 1 周期。

## 4.7 T3 高级房间：新增

### 4.7.1 工业区

工业区内所有工业建筑生产更快。

- 构成要求：至少一栋工业建筑（§4.3，注意与原版「工业机械」不同）；至少一个存储设备；至少一个光照设备；平均装饰度 ≥ **+20**；**32–1000 格**。
- 加成：房间内工业建筑**生产速度 +20%**。
  - 批次建筑（有人操作或无人自动）加快每批进度；连续设备加快处理量，原料和产物同比增加；投入产出比例和功率不变。
  - 与温度效率相乘：温度效率 60% 的建筑在工业区里实际 72%。
  - 硬度磨损按真实生产秒数计，加速后同一批磨损更少。
  - 矿石洗涤器可以满足「至少一栋工业建筑」，但它的清洗速度不受这项加成影响。
  - 发电机不属于工业建筑，不受加成。

### 4.7.2 医疗中心

医院的升级版，提供优先收治与更强的治疗效果。

- 构成要求：分诊床、医务站、配药桌、病诊站**各至少一个**；至少一个厕所；至少一张餐桌；至少一个光照设备；平均装饰度 ≥ **+50**；平均温度 **20–26 ℃**；无工业机械；**24–108 格**。
- 加成：
  - **优先入院**：复制人因患病或失能需要诊疗床时，优先自动分配到医疗中心内空闲、可到达、距离最近的诊疗床；没有可用床位时按原版分配。玩家手动指定的床位不改动。复制人不会被禁足，可以正常使用中心内的餐桌和厕所。
  - **生命回复速度 +50%**：患者在医疗中心的诊疗床接受治疗期间生效，与医院互斥。
  - **辐射拯救者**（群星）：患者在医疗中心的诊疗床**开始治疗**时，若辐射剂量已达到致命值（900 rad × 难度系数），清除全部辐射剂量，并留下永久负面效果「辐射后遗症」：**运动 −6**。后遗症只有一份，多次救治不叠加；未达致命值的辐射病不处理。
- **护理员**：拥有原版「护理员」特质的医生完成诊疗时，患者生命回复速度再 **+25%**，与房间效果叠加，持续到患者离开诊疗床；多名护理员不叠加。护理员加成在医院和医疗中心都有效。

### 4.7.3 舞厅

- 构成要求：至少一个点唱机器人；无其他高级娱乐建筑；至少一个装饰建筑；平均装饰度 ≥ **+65**；平均温度 **20–26 ℃**；无工业机械；**12–96 格**。
- 加成：普通复制人 **士气 +2**；[[超级明星]] **士气 +4、压力 −20%、运动 +3**。

### 4.7.4 街机厅

- 构成要求：至少一个游戏机台；无其他高级娱乐建筑；至少一个装饰建筑；平均装饰度 ≥ **+65**；平均温度 **20–26 ℃**；无工业机械；**12–96 格**。
- 加成：普通复制人 **士气 +2**；[[电子竞技选手]] **士气 +4、压力 −20%、机械 +3**。

### 4.7.5 海滨乐园

- 构成要求：至少一个沙滩椅；至少一个机械冲浪板；无其他高级娱乐建筑；至少一个装饰建筑；至少一个光照设备；平均装饰度 ≥ **+50**；无工业机械；**12–96 格**。没有温度要求。
- 加成：普通复制人 **士气 +2**；[[海滨达人]] **士气 +4、压力 −20%、挖掘 +3**；[[冒险家]] **士气 +4、压力 −20%、建造 +3**。同时拥有两项特质时只按海滨达人结算，不叠加。

### 4.7.6 展览馆

- 构成要求：至少一个基座且正在展示藏品；至少一件杰出艺术品；无其他高级娱乐建筑；至少一个光照设备；平均装饰度 ≥ **+80**；平均温度 **20–26 ℃**；无工业机械；**18–96 格**。
- 加成：普通复制人 **士气 +2**；[[艺术家]] **士气 +4、压力 −20%、艺术 +3**。

### 4.7.7 风洞训练室

- 构成要求：至少一个垂直风洞；无其他高级娱乐建筑；至少一个装饰建筑；平均装饰度 ≥ **+50**；平均温度 **20–26 ℃**；无工业机械；**36–96 格**。
- 加成：普通复制人 **士气 +2**；[[火箭专家]] **士气 +4、压力 −20%、驾驶 +3**。

### 4.7.8 水疗室

- 构成要求：至少一个桑拿浴室或热水浴缸；无其他高级娱乐建筑；至少一个装饰建筑；平均装饰度 ≥ **+50**；平均温度 **26–50 ℃**；无工业机械；**16–64 格**。
- 加成：所有复制人 **士气 +2、压力 −40%**。

### 4.7.9 茶歇室

- 构成要求：至少一个咖啡机或汽水机；至少一个饮水机；无工业机械；平均装饰度 ≥ **+65**；平均温度 **20–26 ℃**；**12–64 格**。
- 加成：所有复制人 **士气 +2、压力 −30%**。

### 4.7.10 任务控制室

实验室的升级版，为火箭提供更强的加速。

- 构成要求：至少一个航天指挥站；除航天指挥站外无其他科学建筑；至少一个光照设备；平均装饰度 ≥ **+20**；无工业机械；**12–64 格**。
- 加成（「额外」指在原版指挥站效果之外另加）：
  - **火箭额外加速 +20%**：房间内的指挥站完成一次助推后，在这次助推的持续时间内（原版 600 s），火箭在原版 +20% 之外再获得基础速度 20% 的加成；本体版同样额外加快任务进度 20%。助推结束即失效。
  - **指挥范围 +2**（群星）：指挥站的可助推范围由 2 格增至 4 格。本体版指挥站不按距离筛选，此项不适用。
  - **科学家翻倍**：完成这次操作的复制人科学属性**大于 20** 时，上述额外量翻倍（额外加速 +40%、范围 +4）；原版 +20% 不翻倍。范围按该指挥站最近一次完成操作的复制人判定。
  - **工作速度 +20%**：指挥站本身的操作速度，与原版实验室 +10% 叠加。
- 读档后，正在进行中的额外加速和翻倍状态不保留，下一次完成操作后恢复。

### 4.7.11 地质研究室

实验室的升级版，增强地质调谐仪。

- 构成要求：至少一个地质调谐仪；除地质调谐仪外无其他科学建筑；至少一个光照设备；平均装饰度 ≥ **+20**；无工业机械；**12–64 格**。
- 加成：
  - **调谐产量 +10%**：房间内的调谐仪广播期间，对目标喷泉另加一项独立的喷发量修正 +10%（原版调谐本身 +20%，合计 +30%），广播结束或换目标时一并撤销。
  - **调谐数量 +1**：原版每座喷泉最多 5 台调谐仪；位于地质研究室的调谐仪可作为第 6 台指向同一喷泉。原版「复制设置」按钮仍按 5 台上限。
  - **科学家翻倍**：完成调谐研究的复制人科学属性**大于 20** 时，额外量翻倍（产量 +20%、数量 +2）。
  - **研究速度 +20%**：调谐仪本身的研究速度，与原版实验室 +10% 叠加。
- 读档后翻倍状态不保留，按未翻倍处理，直到下一次调谐研究完成。

### 4.7.12 航天发射场（群星）

集中发射火箭的开阔场地。

- 构成要求：至少一个火箭发射平台；无生活建筑（§4.3）；**64–2400 格**。没有装饰度要求。
- 加成：
  - **火箭速度 +10%**：从房间内发射平台发射的火箭，本次飞行获得基础速度 10% 的加成，与指挥站加成相加。
  - **燃料消耗 −10%**：同一次飞行中（含发射那一格），每格航程消耗的燃料与氧化剂按 90% 结算。剩余航程、最大航程与每格耗量显示同步折扣；火箭停在房间内的发射平台上时，起飞前的航程显示与目的地可达判定就已按折扣计算。机器人驾驶火箭的数据盘航程上限不变。
  - 发射时判定平台所在房间，着陆即结束；中途换平台或返航不改变本次结果。读档后在途飞行的速度与燃料加成都继续保留，直到着陆。

### 4.7.13 星际货运站（群星）

增强星际物流发射器。

- 构成要求：至少一个星际物流发射器、一个载货拆包器、一个信号播报器、一个信号接收器；**32–360 格**。没有装饰度要求。
- 加成（作用于房间内的星际物流发射器）：
  - **载货飞行速度 +20%**：发射出的载荷在星图上飞行速度 ×1.2。
  - **连发次数 +2**：每轮冷却前可连续发射 8 次（原版 6 次）。
  - **冷却加快 +50%**：冷却计时按 1.5 倍速度递减（原版约 30 s 缩短为约 20 s）。

### 4.7.14 数据机房（仿生人 DLC）

为数据挖掘中心提供低温环境。

- 构成要求：至少一个数据挖掘中心；平均温度**低于 20 ℃**；**12–96 格**。没有装饰度要求，也不限制其他建筑。
- 加成：房间内数据挖掘中心**生产速度 +20%**。数据机房同时仍算实验室，房间内的研究站等科研设施保留原版实验室 +10%。

## 4.10 与其他系统的关系

- 工业区加成与建筑温度效率相乘，磨损按真实生产秒数计（见 [[2. 建筑系统设计#2.8 硬度、磨损与维修]]）。
- 房间温度判定与建筑温区相互独立；高温工业设备会加热所在房间，规划时注意把热量与有温度要求的房间隔开。
- 发电厂沿用原版，发电机的温度效率由建筑系统决定，不受工业区加成。
