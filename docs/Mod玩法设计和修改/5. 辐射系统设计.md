# 5. 辐射系统设计

本篇是辐射系统的分设计文档，目前只有方向，没有已确认规则或数值。

**状态：后续开发，未开始。** 当前 Mod 没有改动辐射的产生、传递或损失；DLC 的辐射建筑（核反应堆、铀素离心机等）保持原版行为。

## 5.1 设计方向

- 增加**辐射耗散系数**，使辐射可以传递，同时也会不断损失。
- 目标是让辐射像热量一样具有空间分布与衰减，而不是只在源点附近判断。

## 5.2 待确认事项

1. 传递介质：只走固体／液体／气体格，还是同时影响真空与开放空间。
2. 耗散与距离的关系：是否按格数指数衰减，是否需要与现有辐射阻挡（铅、深度）叠加。
3. 与建筑系统温控名单的关系：铀素离心机、核反应堆等辐射建筑是否纳入温区；本章不自动扩大 §2 的接入名单。
4. 与电力系统的关系：核反应堆发电与热／辐射耦合是否进入 §3 的损耗或发电结算。
5. 数值初值、界面显示方式与存档口径。

在上述规则确认前，不新增辐射相关建筑、配方或材料属性修改。
