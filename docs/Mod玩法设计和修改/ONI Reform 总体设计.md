# ONI Reform 总体设计

ONI Reform（材料革新）不增加材料数量，也不是单纯重调原版数值，而是改变**材料属性参与建筑、电网和房间运算的方式**，让原本差异不大的材料选择变成真正的工程选择。

本文讲整体思路、三大系统各自解决什么问题，以及它们之间如何互相牵连。具体规则与全部数值见分设计：

# 1. 设计目标

> 让材料属性真正参与运算，使「用什么材料、建在哪里、怎么布局」成为有取舍的工程决定。

## 1.1 设计原则

1. 大多数材料仍然「能用」，不让不同小行星的资源差异直接卡死玩法。
2. 不合适的材料通常不被禁止，而是带来效率、维护、能耗或环境上的代价。
3. 尽量复用原版已有的属性（熔点、硬度、过热温度、装饰度）和系统，只增加少量必要的新规则。
4. 材料不是升级树，而是 trade-off：不存在一种材料在所有场景都最优。
5. 不增加新的纵向玩法，重点是增加原版系统之间的横向联系。
6. 所有选择都不是必须的，但确实存在更合适的选择。

## 1.2 不改变的内容

- 材料的熔点、硬度、比热、导热等物性保持原版（深渊晶石导热改为 0.1 除外），材料照常相变。
- 配方的投入产出比例、产物温度、原版过热伤害速率、维修流程保持原版。
- 复制人对装饰度的感知与士气计算保持原版。
- 低等级房间（厕所、宿舍、食堂等）保持原版，开局难度不变。
- 不修改原版程序集，不另造一套与原版并行的属性体系。

# 2. 建筑系统：温度与硬度

**问题：** 原版建筑只有一个过热温度，而且几乎所有材料都远在过热线以下工作，建材选择没有思考空间；硬度只在挖掘时有用。

**做法：** 给 29 栋工业建筑加上「工作温区」和「硬度要求」两条约束。

- **工作温区。** 每栋建筑有一个由建筑类型决定的最低工作温度，最高工作温度由主建造材料决定：

  $$T_{max}=0.75\times T_{熔点}(\mathrm{K})\times(1+\text{材料过热加成})$$

  这同时也是建筑的过热温度。每个配方另有最佳温区：在最佳温区内效率 100%，偏离越远效率越低。低熔点材料造的精炼炉可能根本够不着高温配方的最佳区。
- **预热与补热。** 金属精炼器等高温建筑自带电加热，玩家用 20–4000 W 滑条决定加热功率；加热要耗电，注入的是热量，升温快慢取决于建材热容和保温。
- **运行模式。** 未接温区输出线时为「默认模式」，在整个工作温区内都可生产；接上输出线即为「控制模式」，只在最佳温区内生产。另有「强制运行」开关，在特殊温度下继续生产，代价是效率和过热风险。
- **订单排程。** 订单按添加顺序轮换执行，同一配方可重复添加。玩家会倾向把温区相近的配方排在一起，生产排程因此成为热管理的一部分。
- **硬度。** 主建造材料硬度低于建筑要求时，建筑仍可生产，但按实际生产时间慢慢磨损扣血。低温低效生产会拉长生产时间，磨损也随之增加。

此外，材料的过热加成在全游戏范围改为百分比（原有正向加成统一 +60%），深渊晶石可作为矿物原料建材，所有接受金属矿石的槽位都可以改用精炼金属。

# 3. 电力系统：线路损耗

**问题：** 原版电力只有功率一个变量，超大一体化电网、长距离高负载输电都没有代价，线路规划没有意义。

**做法：** 每台用电设备按「从供电端到它的最短实际线路」计算输电损耗。

- 线路越长、负载越高、导线容量越大而负载偏低、材料电导率越差，损耗越大。
- 多电源时设备先从线路最近的电源取电；变压器两侧分开结算；电池充电、放电分别记账。
- 导线类型决定容量，建造材料决定电导率（铜最好，铁矿、铅等较差），混合线材按分段累计。
- 每个电网的损耗汇总为一笔真实支出，在电网信息卡与能源报告中单独显示。

理想体验：前期随便接，损耗很小；中期工业区变大，开始感到浪费；后期主动分区、升级主干线、优化高功率设备布局。

# 4. 房间系统：分级与环境

**问题：** 原版房间加成少，建好之后缺少继续经营的理由。

**做法：** 把房间分为 T1 基础、T2 改善、T3 高级三级。T1 保持原版；T2 加入淋浴间、人造公园，并给医院增加治疗加成；T3 房间普遍要求**平均装饰度**，部分还要求**平均温度**，并给出更强的效果。

- 新增 16 个房间：淋浴间、人造公园、工业区、医疗中心、舞厅、街机厅、海滨乐园、展览馆、风洞训练室、水疗室、茶歇室、任务控制室、地质研究室、航天发射场、星际货运站、数据机房。
- 改造 3 个原版房间：私人卧室与宴会厅增加装饰度和温度条件，医院增加生命回复加成。
- 新增 6 项先天偏好特质（超级明星、电子竞技选手、海滨达人、冒险家、艺术家、火箭专家），持有者在对应娱乐房间获得额外加成。
- 13 种材料获得新的或更高的装饰度加成，让建材选择也影响房间等级。

# 5. 系统间的联动

三个系统同时启用时，彼此之间有以下交叉影响：

| 联动 | 规则 |
| --- | --- |
| 工业区 × 温度效率 | 工业区内工业建筑生产速度 ×1.2，与温度效率相乘。温度效率 60% 的建筑在工业区里实际为 72%。 |
| 工业区 × 硬度磨损 | 磨损按真实生产秒数计。房间加速让一批更快做完，同一批的磨损相应减少，不会因加速多算。 |
| 内置加热 × 电网 | 加热功率是真实用电需求，与生产用电一起参与线路损耗和电线过载判断。金属精炼器生产 1200 W 加默认加热 1200 W，共 2400 W，已超过导电电线 2 kW 的上限。 |
| 发电机温区 × 电网 | 六种燃料发电机受温度效率影响：低温时每秒发电量、燃料消耗和排放同比下降，每千克燃料的电量不变。 |
| 材料 × 房间装饰度 | 陶瓷、花岗岩、钢、玻璃等材料的装饰度加成提高，建造房间时选材会影响平均装饰度能否达标。 |
| 房间温度 × 建筑温区 | 两套判定互相独立：房间温度只决定房间类型，不影响建筑的生产许可；建筑的工作温度只看建筑本体温度，不看所在房间。 |
| 高温工业 × 房间 | 金属精炼器等高温建筑会显著加热所在房间，工业区本身没有温度要求，但要注意不要把热量泄漏到有温度要求的生活区房间。 |

# 6. 辐射系统（规划中）

材料长期处在强辐射中会自己带上放射性：建筑与砖块累积活化度并自身放射，液体、气体和天然格带上原版放射性污染物，离开辐射源后按半衰期衰减。另计划给辐射增加耗散系数，使辐射在空间中传递、同时不断衰减。见 [[5. 辐射系统设计]]。

# 7. 系统开关

四个系统可以分别开关：在游戏「模组」菜单本 Mod 那一行点「选项」，每个系统一个按钮，点一下在「开启」「关闭」之间切换，保存后重启游戏生效。默认全部开启。

| 关闭的系统 | 效果 |
| --- | --- |
| 工业 | 工业建筑回到原版：没有工作温区、内置加热、订单排程与硬度磨损，材料分类与过热改造恢复原版。 |
| 电力 | 电网回到原版结算，没有线路损耗与电池、变压器分账。 |
| 房间 | 没有新增房间与房间分级，原版房间恢复原版条件和加成；复制人已获得的偏好特质暂时不显示、不起作用，重新开启后恢复。 |
| 辐射 | 建筑不再活化，液体、气体不再被写入放射性污染物；已有的污染物按原版规律自然衰减。 |

系统之间的联动（第 5 节）只在两边都开启时出现，例如关闭房间后工业区的 ×1.2 也随之消失。

在已有存档里中途关闭某个系统：该系统记在建筑上的数据（工业订单与磨损进度、建筑活化度、航天飞行加成等）会在下次存档时丢失，复制人身上由该系统给的效果暂时失效。之后重新开启，系统从头开始计算。建议关闭前先备份存档。
